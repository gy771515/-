# 移动机器人路径规划与仿真系统

基于 Python 的差速移动机器人路径规划、轨迹跟踪与可视化仿真平台，用于快速验证全局规划算法和运动控制策略。

## 功能特性

### 路径规划
- 集成经典 Dijkstra 算法与高效 A* 启发式搜索算法
- 支持动态调整避障安全权重，权衡路径长度与安全性
- 随机地图生成与连通性保证机制

### 轨迹处理
- "高斯平滑+弹性冲突修正"复合策略，平衡平顺性与安全性
- 线性插值轨迹稠密化，保证运动连续性

### 运动控制
- 串级双环 PID 控制器（外环位置补偿+内环姿态追踪）
- 带符号横向误差与航向误差计算
- 自适应速度修正与摩擦系数模拟
- 安全限幅与死区控制，保护执行器

### 仿真架构
- 工业级二进制通信协议（0xAA 0x55帧结构），实现软硬件解耦
- Mock下位机模拟真实硬件响应
- "多步计算、单帧渲染"架构，支持最高50倍物理加速
- PyQt5 交互式可视化界面，实时报文监控

## 安装与运行

### 环境依赖
- Python 3.10+
- NumPy
- PyQt5
- Matplotlib
- SciPy


## 使用说明

1. **场景配置**：点击"设置起点"/"设置终点"在地图上定位，或点击"随机生成障碍物"构建测试环境
2. **路径规划**：选择算法（A*或Dijkstra），调整安全权重，点击规划
3. **参数调优**：根据需要修改PID参数、摩擦系数与最大速度
4. **开始仿真**：建立通信连接，点击"开始仿真"观察轨迹跟踪效果
5. **功能演示**：勾选"自动修正"观察碰撞时的应急处理

## 实验成果

- **规划性能**：A*算法在复杂环境中搜索节点数仅为Dijkstra的30%
- **控制精度**：引入横向补偿外环后，S型轨迹最大横向误差降低85%
- **仿真效率**：50倍加速机制，快速完成大规模参数扫描实验
